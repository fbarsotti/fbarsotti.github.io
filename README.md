# fbarsotti.github.io

Sito personale di Francesco Barsotti, pubblicato con GitHub Pages.

## Struttura
- `/` home
- `/assets/` logo e risorse condivise
- `/apps/<app>/` pagina di dettaglio di un'app
- `/apps/<app>/privacy/` privacy policy (link usato sull'App Store: non spostare)
- `/apps/<app>/release-notes/` note di rilascio (futuro)
