# fbarsotti.github.io

Sito personale di Francesco Barsotti, pubblicato con GitHub Pages.

## Struttura
- `/` home
- `/assets/` logo e risorse condivise
- `/projects/<app>/` pagina di dettaglio di un'app
- `/projects/<app>/privacy/` privacy policy (link usato sull'App Store: non spostare)
- `/projects/<app>/release-notes/` note di rilascio (futuro)

## Progetti
- Risuscitò - Canti del Cammino: https://fbarsotti.github.io/projects/risuscito/ · privacy: https://fbarsotti.github.io/projects/risuscito/privacy/

`/apps/…` contiene solo reindirizzamenti ai vecchi indirizzi (verso `/projects/…`).
